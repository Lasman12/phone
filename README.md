# הטלפון שלי 📱

אתר שהוא טלפון מדומה: WhatsApp, YouTube, מוזיקה, אנשי קשר ו-Google.
אתר סטטי (HTML/CSS/JS בלבד), כך שהוא רץ ב-GitHub Pages בחינם.

## מבנה

```
index.html          מסגרת הטלפון ומסך הבית
css/style.css       כל העיצוב
js/core.js          הליבה: פתיחת אפליקציות, שמירה, אנשי קשר, מסך שיחה
js/apps/*.js        כל אפליקציה בקובץ משלה
```

## הוספת אפליקציה

1. יוצרים `js/apps/שם.js` עם `Phone.registerApp({...})` (דוגמה בראש `js/core.js`).
2. מוסיפים שורת `<script>` ב-`index.html`.

## הרצה במחשב

```
python -m http.server 8123
```
ואז פותחים http://localhost:8123

## שימו לב

- הנתונים (הודעות, אנשי קשר) נשמרים בדפדפן של כל מבקר בנפרד.
- האתר מסומן `noindex` כדי שלא יופיע בגוגל, אבל כל מי שיש לו את הקישור יכול להיכנס.
